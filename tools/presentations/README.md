# Presentations & Slide Show Tools for Clyde

Directory for presentation, slide show, and document generation tools.

## Subdirectories

- `presentations/` — Slide deck generation
- `documents/` — Document creation (Word, PDF)
- `html-decks/` — HTML-based slide decks
- `ascii-present/` — ASCII-based slide shows

## Planned Features

- HTML/CSS slide deck generation (Stripe, Linear, Vercel-style)
- Python-pptx: PowerPoint creation and editing
- Google Slides integration
- Manim CE animations for presentation slides
- ASCII video: convert to colored ASCII MP4/GIF for slides
- Songwriting and AI music prompts for presentation intros
- Claude-design: One-off HTML artifacts (landing, deck, prototype)
- Design-md: Google's DESIGN.md token spec file authoring/validation/export

## Output Formats (planned)

- HTML/CSS slide decks
- PowerPoint (.pptx) files
- PDF presentations
- ASCII/MPEG slide video
- Web-based interactive presentations
