# Browser Control Tools for Clyde

Directory for browser automation and web interaction tools.

## Subdirectories

- `automation/` — Browser automation scripts
- `scraping/` — Web scraping and data extraction
- `interactions/` — Click/ fill / form interaction scripts
- `monitoring/` — Website monitoring and change detection
