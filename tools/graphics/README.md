# Graphics Tools for Clyde

Directory for graphic design and ASCII art tools.

## Subdirectories

- `ascii-art/` — ASCII art generation and conversion
- `diagrams/` — SVG/diagram generation
- `color/` — Color palette and theme tools
- `charts/` — Chart and graph generation

## Available Tools (planned)

- ASCII video: colored ASCII MP4/GIF generation
- Architecture diagrams (dark-themed SVG)
- Infographics: 21 layouts × 21 styles
- p5.js sketches: generative art, shaders, interactive, 3D
- Popular web designs: 54 design systems as HTML/CSS
- ASCII art: various styles and conversions
