# Video Tools for Clyde

Directory for video processing and generation tools.

## Subdirectories

- `scripts/` — Python/bash scripts for video operations
- `ffmpeg/` — FFmpeg-based operations
- `ascii/` — ASCII video conversion
- `manim/` — Math animation generation

## Available Tools (planned)

- Video conversion and compression
- ASCII video generation
- Manim CE animations (3Blue1Brown style)
- ASCII video: convert video/audio to colored ASCII MP4/GIF
- Songsee: Audio spectrograms/features (mel, chroma, MFCC) via CLI
